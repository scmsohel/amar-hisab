# Amar Hisab — Web Prototype

A Bengali personal-finance dashboard prototype built with React, TypeScript, Vite, Recharts, Lucide icons and Motion for React.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build check

```bash
npm run build
```

## Current prototype features

- Responsive dashboard layout and navigation
- Summary cards, wallet previews and demo financial charts
- Demo transaction search and income/expense filter
- Demo income/expense entry form
- Light/dark theme toggle
- Premium-smooth UI micro-interactions and reduced-motion CSS support

## Important: not production-ready

This is a front-end-only prototype. Financial figures are sample data. The app is not connected to a backend or PostgreSQL; demo entries are not persisted. Authentication, invitation registration, transfers, complete CRUD, exports, real reports, automated tests and production deployment remain to be implemented.

See [prototype status](docs/PROTOTYPE-STATUS.md).

The initial implementation is on the `web-prototype` branch. The `main` branch has not been changed.
